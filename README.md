# 🗺️ Tourist Itinerary Generator — Frontend

An interactive, user-facing web application designed to generate and customize optimized travel itineraries based on user constraints, time durations, and preference scores. Built with React and TypeScript, this frontend connects seamlessly to an AI/algorithmic recommendation backend.

---

## ✨ Features

- **Interactive Itinerary Builder:** Custom input controls for trip duration, budget, target locations, and activity preferences.
- **Dynamic Optimization Display:** Real-time visual feedback rendering optimized travel routes and scheduled stops.
- **Interactive Maps & Location Cards:** Detailed views of recommended tourist destinations, complete with time allocations and constraint tags.
- **User Authentication & Saved Trips:** Persistent state management for authenticated users to save, review, and modify generated itineraries.
- **Responsive UI:** Clean, modern interface designed for mobile and desktop travel planning.

---

## 🛠️ Tech Stack

- **Framework:** [React](https://reactjs.org/) (TypeScript)
- **State Management & Data Fetching:** Context API / React Query / Axios / MongoDB Atlas
- **Styling:** Tailwind CSS / CSS Modules
- **Build Tool:** Vite / Create React App
